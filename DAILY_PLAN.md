# 14-day plan - one small real improvement per day

Tick a box and commit it the day you do it (a one-line edit to this file plus the change itself is enough).
Each item is small, so it fits in a short chat or a few minutes of your own editing.

- [ ] Day 1  - Write down your trading rules (entry, exit, risk per trade) in `RULES.md`
- [ ] Day 2  - Add a screenshot of each chart to the README
- [ ] Day 3  - Add a "Troubleshooting" section to the README (MT5 not connecting, Fyers login expired)
- [ ] Day 4  - Add a keyboard shortcuts list to the README (and a `?` help popup in the chart)
- [ ] Day 5  - Add a trade journal note box in the Trades bar (one text note per trade)
- [ ] Day 6  - Add a "daily P/L" line in the growth panel
- [ ] Day 7  - Add an alert when price crosses a level (sound + on-screen message)
- [ ] Day 8  - Save and load chart layouts (indicators + drawings) by name
- [ ] Day 9  - Add an indicator preset button (your favourite SMMA/EMA/ATR set in one click)
- [ ] Day 10 - Add the Wyckoff indicator (phase labels) - first version
- [ ] Day 11 - Tune the Wyckoff indicator on gold and Nifty history
- [ ] Day 12 - Add a session-times shading (Asia / London / New York) on the gold chart
- [ ] Day 13 - Add a backtest of your own rules from `RULES.md`
- [ ] Day 14 - Review the week's trades with the growth panel and write the lessons in `JOURNAL.md`
